Confidentialité et sauvegardes

Les données sont synchronisées dans Supabase et les photos dans un compartiment privé. Le fichier JSON téléchargé contient tous les prix, stocks et photos : protégez-le. Une restauration modifie l'inventaire de tous les appareils et ne peut pas récupérer les données que vous n'aviez pas sauvegardées. Les téléchargements sont lancés après votre clic : le navigateur décide du dossier d'enregistrement.
